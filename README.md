# cv-ai-warehouse-inspector
End-to-end computer vision pipeline for automated warehouse safety monitoring — detecting PPE compliance, restricted-zone violations, and worker-forklift collision risk from CCTV feeds. Work in progress.

## Status: In Progress 🚧
